## Requisitos

É necessário ter instalado:

* Node.js em uma versão LTS recente;
* npm, instalado junto com o Node.js;
* navegador e conexão com a internet.

Verifique a instalação:

```powershell
node --version
npm --version
```

## Primeira execução

Entre na pasta do frontend:

```powershell
cd "C:\Users\gabri\OneDrive\codigos\ProjetoDePesquisa\01 - SiraRQlite\google-login-frontend"
```

Instale as dependências:

```powershell
npm install
```

Inicie o projeto:

```powershell
npm run dev
```

Abra o endereço mostrado no terminal, normalmente:

```text
http://localhost:5173
```

Para encerrar o projeto, pressione `Ctrl + C` no terminal.
